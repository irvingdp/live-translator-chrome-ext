# 分流標籤

skill 以五種標準分流角色來描述 issue 狀態。這份文件把這些角色對應到這個 repo 的 issue tracker 實際使用的標籤字串。

| mattpocock/skills 的標籤 | 我們 tracker 的標籤 | 意義                                   |
| ------------------------ | ------------------- | -------------------------------------- |
| `needs-triage`           | `needs-triage`      | 需要維護者評估這個 issue               |
| `needs-info`             | `needs-info`        | 等待回報者提供更多資訊                 |
| `ready-for-agent`        | `ready-for-agent`   | 規格完整，可交給無人值守的 agent 處理  |
| `ready-for-human`        | `ready-for-human`   | 需要人來實作                           |
| `wontfix`                | `wontfix`           | 不會處理                               |

當 skill 提到某個角色（例如「apply the AFK-ready triage label」），使用上表中對應的標籤字串。

如果實際使用的標籤不同，修改「我們 tracker 的標籤」這一欄即可。
