# Live Translator

A Chrome extension that turns the audio of the current tab into bilingual captions (original and translation) shown over the page.

## Language

### Caption modes

**Live mode** (即時模式):
Captions translated from the audio the viewer is hearing right now, so they always trail the speech. Gemini Live works this way (Deepgram + DeepL did too, until it was removed in 1.5.0).
_Avoid_: Realtime mode, normal mode

**Read-ahead mode** (預讀模式):
A separate caption mode that translates real upcoming audio before the viewer reaches it, so each caption appears as its speech starts. It never predicts what will be said.
_Avoid_: Prediction, prefetch, look-ahead translation

### Read-ahead

**Main player** (主播放器):
The media element the viewer is actually watching and hearing.
_Avoid_: Original video, foreground player

**Buffer tap** (緩衝擷取):
Reading upcoming audio straight from what the main player has already downloaded but not yet played. Used where the main player streams its media in pieces (YouTube).
_Avoid_: Interceptor, sniffer, prefetch

**Shadow player** (影子播放器):
A hidden, muted second copy of the same media that plays ahead of the main player and supplies the audio for read-ahead. Used for plain video files, where there is no buffer to tap.
_Avoid_: Ghost player, background player, preloader

**Chunk** (片段):
A stretch of upcoming audio sent for translation in one request, normally cut at a pause in speech.
_Avoid_: Segment, batch, window

**Lead** (提前量):
How far, in media time, upcoming audio has been read ahead of the main player. It grows up to 30 seconds.
_Avoid_: Offset, buffer, delay

**Hold** (讀取等待):
The main player paused by the extension, showing "讀取音訊中…" (waiting for audio), "讀取字幕中…" (waiting for the caption track) or "翻譯中…" (waiting for the translation), because it reached media time with no translation yet. It is distinct from a pause by the viewer.
_Avoid_: Buffering, warm-up, stall

**Word highlight** (逐字標示):
In read-ahead mode, the cue's original line marked word by word as the speaker says each word: words already said shown normally, the current one marked, the rest dimmed. Only where the recognizer timed each word (Whisper); a cue without word timing shows plainly. The viewer can turn it off.
_Avoid_: Transcript (逐字稿), karaoke mode

**Caption track** (字幕軌):
Timed captions the uploader published with the video. When read-ahead finds one in the spoken language, it reads the sentences from it instead of from the recognizer, unless the viewer turned caption tracks off; when it also finds one in the target language, it takes the translation from that instead of from the translator. Captions the site generated by its own speech recognition, and machine translations the site makes of a track, are not caption tracks.
_Avoid_: Subtitles, CC, transcript

**Recognizer** (語音辨識):
The read-ahead service that turns a chunk's audio into timed sentences: Gemini (which also translates), Groq Whisper, or Local Whisper.
_Avoid_: Transcriber (the setting's old name for the caption mode), ASR provider

**Local Whisper** (本地 Whisper):
The recognizer that runs a Whisper model on the viewer's own computer, in the browser: no key and no quota, but the model must be downloaded once and the computer must support WebGPU.
_Avoid_: Offline mode, on-device ASR

**Translator** (翻譯):
The read-ahead service that translates the recognizer's sentences when the recognizer does not: Chrome's built-in Translator, or where it cannot, Google's web translation.
_Avoid_: Translation provider, MT

**Cue** (定時字幕):
A read-ahead caption pinned to the media time its speech starts. It appears when the main player reaches that time.
_Avoid_: Timed caption, subtitle entry
